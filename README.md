# Hermes Agent Project

Repository for the Hermes Agent project.

## News Aggregator Site

The static site is hosted via **GitHub Pages** at:
https://thetvforthelivingroom-gif.github.io/hermes-agent-project/

It displays the latest news articles generated by the project.

## Updating the Site

Follow these steps to add new stories and rebuild the site:

1. **Create a new article**
   - Add a markdown file in the `articles/` directory (e.g., `articles/2026-09-15-new-event.md`).
   - Include a front‑matter block with `title`, `date`, and optional `tags`.
2. **Generate the static site**
   - Run the site generator (e.g., `make site` or the provided script `generate_site.sh`).
   - This will produce the `index.html` and related assets in the `public/` folder.
3. **Commit and push**
   ```bash
   git add articles/*.md public/
   git commit -m "Add new article: <title>"
   git push origin main
   ```
4. **Trigger GitHub Pages build**
   - The push to `main` (or the `gh-pages` branch if used) automatically triggers a GitHub Pages build.
   - You can monitor the build status via the GitHub API or the repository's **Pages** settings page.
5. **Verify deployment**
   - Visit the site URL above and confirm the new article appears.

## Development Workflow

- Use `git pull` to keep your local clone up‑to‑date.
- Run tests with `make test` before committing.
